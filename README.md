# 🤖 Jimmy's Gold Trading Automation System

This is a 14-agent automated trading system for XAUUSD on Exness MT5, following ICT/SMC institutional methodologies. The system uses LangGraph for orchestration and leverages Google Gemini for decision making.

## 🪟 Windows Deployment & Testing Guide

Because the official `MetaTrader5` Python library relies heavily on Windows processes to communicate directly with the trading terminal, this bot **must** be executed natively on Windows.

### 🛠️ Step 1: Environment Setup

1. **Install Python for Windows**
   * Download and install Python 3.11 (or higher) from `python.org`.
   * **CRITICAL:** During installation, make sure you check the box that says **"Add Python to PATH"**.

2. **Install Exness MT5 Terminal**
   * Download and install the Exness MT5 terminal.
   * Log in to your trial account:
     * **Login:** `436140795`
     * **Password:** `Agents@123`
     * **Server:** `ExnessKE-MT5Trial9`
   * Open the **Market Watch** panel (Ctrl+M) and ensure the symbol **`XAUUSDm`** is visible. If it's not, right-click -> Symbols -> Add it.

3. **Enable Algo Trading in MT5**
   * In MT5, go to `Tools` -> `Options` -> `Expert Advisors`.
   * Check the box for **"Allow algorithmic trading"**.

### 🧪 Step 2: The Connection Test

Before running the full system, you can verify the connection by running a simple test. 

Create a file named `test_mt5.py` and run it:

```python
import MetaTrader5 as mt5

def test_connection():
    if not mt5.initialize():
        print(f"initialize() failed, error code: {mt5.last_error()}")
        return

    authorized = mt5.login(436140795, password="Agents@123", server="ExnessKE-MT5Trial9")
```

### 🚀 Step 3: Running the Full 14-Agent Bot

1. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

2. **Verify the `.env` File**
   Ensure your `.env` file is properly populated (refer to `.env.example`). Make sure to provide your `TELEGRAM_CHAT_ID` and `GEMINI_API_KEY`.

3. **Start the Bot**
   With the MT5 terminal actively running in the background, start the master orchestrator:
   ```bash
   python main.py
   ```
