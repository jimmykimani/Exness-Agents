# 🪟 Windows Deployment & Testing Guide

This document is designed for you (and any AI agent assisting you) when you move this project to your Windows machine or Windows VPS. 

Because the official `MetaTrader5` Python library relies heavily on Windows processes to communicate directly with the trading terminal, this bot **must** be executed natively on Windows.

## 🛠️ Step 1: Environment Setup

1. **Install Python for Windows**
   * Download and install Python 3.11 (or higher) from `python.org`.
   * **CRITICAL:** During installation, make sure you check the box that says **"Add Python to PATH"**.

2. **Install Exness MT5 Terminal**
   * Download and install the Exness MT5 terminal.
   * Log in to your trial account:
     * **Login:** `436140795`
     * **Password:** `Agents@123`
     * **Server:** `ExnessKE-MT5Trial9`
   * Open the **Market Watch** panel (Ctrl+M) and ensure the symbol **`XAUUSDm`** is visible. If it's not, right-click -> Symbols -> Add it.

3. **Enable Algo Trading in MT5**
   * In MT5, go to `Tools` -> `Options` -> `Expert Advisors`.
   * Check the box for **"Allow algorithmic trading"**.

## 🧪 Step 2: The Connection Test

Before running the massive 14-agent system, we must verify the Python-to-MT5 bridge works. 

Create a file named `test_mt5.py` on your Windows machine and paste this code:

```python
import MetaTrader5 as mt5

def test_connection():
    print("Initializing MT5...")
    if not mt5.initialize():
        print(f"initialize() failed, error code: {mt5.last_error()}")
        return

    login = 436140795
    password = "Agents@123"
    server = "ExnessKE-MT5Trial9"

    print(f"Connecting to {server}...")
    authorized = mt5.login(login, password=password, server=server)
    
    if authorized:
        print("✅ SUCCESS! Connected to Exness.")
        
        # Test pulling XAUUSDm
        symbol = "XAUUSDm"
        tick = mt5.symbol_info_tick(symbol)
        if tick:
            print(f"📊 Current {symbol} Price:")
            print(f"Bid: {tick.bid} | Ask: {tick.ask}")
        else:
            print(f"❌ Connected, but failed to get tick for {symbol}. Make sure it is in Market Watch.")
            
        account_info = mt5.account_info()
        if account_info:
            print(f"💰 Balance: ${account_info.balance}")
            
    else:
        print(f"❌ Login failed, error code: {mt5.last_error()}")

    mt5.shutdown()

if __name__ == "__main__":
    test_connection()
```

Open Command Prompt / PowerShell, install the library, and run the test:
```bash
pip install MetaTrader5
python test_mt5.py
```
*(If this succeeds, you are 100% ready to run the full bot).*

## 🚀 Step 3: Running the Full 14-Agent Bot

1. **Transfer the Project**
   * Move the entire `GoldAgent` folder from your Linux machine to your Windows machine.

2. **Install Dependencies**
   * Open Command Prompt in the `GoldAgent` directory.
   * Run the installer:
     ```bash
     pip install -r requirements.txt
     ```

3. **Verify the `.env` File**
   * Ensure your `.env` file transferred properly and looks like this:
     ```env
     MT5_LOGIN=436140795
     MT5_PASSWORD=Agents@123
     MT5_SERVER=ExnessKE-MT5Trial9
     GEMINI_API_KEY=your_gemini_api_key
     TELEGRAM_BOT_TOKEN=your_telegram_bot_token
     TELEGRAM_CHAT_ID=your_chat_id  # <--- MUST FILL THIS IN
     TRADING_MODE=demo
     AUTO_EXECUTE=false
     ```

4. **Start the Bot**
   * With the MT5 terminal actively running in the background, start the master orchestrator:
     ```bash
     python main.py
     ```
